# عرض الفيلا ثلاثي الأبعاد — زرار "تحديث العرض" للمهندسين

كل مهندس يقدر يرفع عرض أي فيلا من الريفت بضغطة زرار، ويطلع لكل فيلا رابط خاص بيها ينفع يتبعت للمالك.

## إزاي بيشتغل

1. المهندس يفتح موديل الفيلا في Revit ويضغط **NITAQ ← تحديث العرض**.
2. الزرار بيقرا الموديل بس (مافيش أي تعديل على ملف الريفت)، ويجهّز العرض، ويرفعه على السحابة.
3. بيظهر **رابط الفيلا**: بيتنسخ تلقائيًا ويتفتح في المتصفح.
4. أي تحديث بعد كده للفيلا نفسها بيظهر على **نفس الرابط**، فالمالك مش محتاج رابط جديد.

اسم الفيلا في الرابط بيكون حروف إنجليزية صغيرة وأرقام وشرطات، زي `villa-4067`. نفس الاسم = نفس الفيلا = نفس الرابط.

## تثبيت الزرار عند مهندس (مرة واحدة لكل جهاز)

المطلوب على الجهاز: **Revit** و **pyRevit**.

1. خد فولدر **NITAQ-Showcase** من المكان المشترك في المكتب.
2. اضغط كليك يمين على `install.ps1` ← **Run with PowerShell**.
3. لو Node.js مش موجود، الملف بيثبّته لوحده.
4. لو الفولدر جالك باسمك (ملف zip من المسؤول)، المفتاح جواه ومش هتكتب حاجة. غير كده حط **مفتاح المهندس** اللي استلمته (بيبدأ بـ `nsk_`).
5. افتح Revit (أو اضغط Reload في تبويب pyRevit)، وهتلاقي تبويب **NITAQ** فيه زرار **تحديث العرض**.

## للمسؤول: إدارة المهندسين والروابط

**أسهل طريقة لمهندس جديد (من غير مفتاح الخدمة):**

1. `node tools/revit/pack-showcase-extension.mjs --engineer "اسم المهندس"`
2. بيطلع `dist/engineers/<الاسم>.zip` (المفتاح جواه) و `<الاسم>.sql`.
3. شغّل سطر الـ SQL في مشروع العرض على Supabase (SQL Editor). بيتسجل فيه بصمة المفتاح بس، مش المفتاح نفسه.
4. ابعت الـ zip للمهندس ده بس. عمل نفس الأمر لنفس الاسم تاني بيلغي مفتاحه القديم.
5. إيقاف مهندس من الـ SQL Editor: `update public.showcase_publishers set active = false where name = 'اسم المهندس';`

الأوامر دي بتتشغّل من فولدر المشروع على جهاز المسؤول بس (عليه مفتاح الخدمة في `.env`):

| المطلوب | الأمر |
|---|---|
| مفتاح لمهندس جديد (بيظهر مرة واحدة) | `node tools/revit/showcase_publish.mjs publisher add "اسم المهندس"` |
| عرض المهندسين وآخر استخدام | `node tools/revit/showcase_publish.mjs publishers` |
| إيقاف مفتاح مهندس (لو ساب الشغل مثلًا) | `node tools/revit/showcase_publish.mjs publisher off "اسم المهندس"` |
| رابط إضافي لفيلا (مثلًا لمالك تاني) | `node tools/revit/showcase_publish.mjs link villa-4067 "المالك"` |
| روابط فيلا وعدد مرات الفتح | `node tools/revit/showcase_publish.mjs links villa-4067` |
| إيقاف رابط | `node tools/revit/showcase_publish.mjs disable <token>` |
| تجهيز فولدر التثبيت للمهندسين | `node tools/revit/pack-showcase-extension.mjs` (بيطلع في `dist/NITAQ-Showcase`) |

## الأمان

- بيانات الفيلات مش على GitHub. بتتخزن في مشروع Supabase منفصل وخاص، ومحدش يقدر يفتحها غير بالرابط.
- مفتاح كل مهندس بيسمح له يرفع ويعمل روابط بس. ممكن يتوقف في أي وقت من غير ما يأثر على الباقيين.
- مفتاح الخدمة (الصلاحية الكاملة) بيفضل على السحابة وجهاز المسؤول بس، وعمره ما بيتحط عند مهندس.
