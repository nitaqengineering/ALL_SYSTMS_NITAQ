# استكمال تجربة الحفظ والتحديث

- مؤشر حالة الحفظ بجانب زر حفظ الآن، بالإضافة إلى الذيل، مع role=status وaria-live=polite. لا يحجب الجدول.
- فحص النسخة يقارن هوية السكربتات المرقمة وروابط التنسيق وCSS المضمّن في head. يتجاهل أنماط التنبيه المضافة أثناء التشغيل، ولا يظهر تنبيهًا عند فشل الاتصال.
- تبقى ملفات CSS الخارجية بحاجة لتحديث ?v عند تغيير محتواها. لا يفحص هذا التحديث محتوى ملفات CSS الخارجية دون تغيير الرابط.
- لم يُغيّر التنقل بين أقسام البوابة لأنه يحتفظ بالإطارات المفتوحة أصلًا. تحذير الخروج أثناء حفظ معلق ومنع الاستعادة أثناء الحفظ موجودان ومختبران.
- npm run check ناجح، مع اختبار الحفظ الخلفي وفحص النسخة الجديد. لا تعديل SQL أو بيانات إنتاج.
- ما زال القبول البصري بعد الدخول والطباعة ووحدة الإشراف الكاملة وإعداد أسرار النسخ الاحتياطي أعمالًا مستقلة غير منجزة؛ لا يدعي هذا الإصدار اكتمالها أو يرسل دعوات للمستخدمين.
