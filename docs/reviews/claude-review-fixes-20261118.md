## الفحوص
- npm run build: ناجح، وأعيد بناء app.js للحسابات وCRM.
- npm run check: ناجح، بما يشمل اختبارات التقرير والنوافذ الجديدة والربط والحفظ والصلاحيات وبوابة النشر والنسخ الاحتياطي الوهمي.
- اختبارات النوافذ تستخدم DOM double، واختبار التقرير يولد HTML ويختبر دالة اللون؛ لا يمثلان فحص متصفح أو React فعلي.
- لم تتغير دوال SQL أو قواعد العمل في هذه الجولة؛ نتائج محاكاة 5000 مشروع و10 مستخدمين السابقة لا تعني قياس أداء الإنتاج.
- لم أكرر محاولة المتصفح التي أوقفتها المراجعة التلقائية بسبب حد الاستخدام، ولم أتجاوز ذلك المنع.
