# الحفظ التلقائي بدون حجب الواجهة

- حفظ تلقائي بعد ثانية من آخر تعديل مع تجميع اللقطات غير المرسلة.
- التعديلات أثناء الطلب تنتظر تأكيده، ثم تُحسب مقارنة بالنسخة المؤكدة وتُرسل بالتتابع؛ لا طلبان متوازيان ولا تبديل لمعرف عملية غير مؤكدة.
- زر حفظ الآن يرسل فورًا. مؤشر savehint يعرض الانتظار والحفظ والنجاح؛ لا شاشة كبيرة أو toast في كل حفظ ناجح.
- الشاشات الحاجبة تظل للأخطاء والتعارض والدخول والقراءة الأولى. عند فشل الطلب تبقى التعديلات الجديدة في الذاكرة وتتوقف قائمة الإرسال حتى تأكيد الطلب الأصلي.
- تنبيه إغلاق الصفحة يبقى ما دام هناك حفظ معلق، وتُمنع الاستعادة أثناء الحفظ. لا تُرسل طلبات شبكة عند إغلاق الصفحة ولا يُدّعى حفظ لم يؤكده الخادم.
- npm run check ناجح، ويتضمن اختبار check-background-save.mjs باستخدام snapshot وworkspaceRequest وwriteDb وsaveSharedWorkspace الفعلية مع RPC مؤجل ومؤقتات اصطناعية: تجميع التعديلات، نفس المشروع، إعدادات متلاحقة، زر الحفظ الفوري، إعادة الطلب غير المؤكد بنفس المعرف، تراجع قبل الإرسال، التعارض، ومنع استعادة متزامنة.
- لا SQL جديد أو تعديل بيانات إنتاج في هذا الإصدار. لم يجر قبول بصري بعد الدخول؛ الفحوص الآلية لا تثبت تجربة متصفح فعلية.
