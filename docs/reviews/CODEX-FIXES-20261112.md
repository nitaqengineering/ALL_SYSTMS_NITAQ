## ما تغير
1. ترحيل 003 لحماية إنشاء العقود المالية ورسوم المشاريع من المهندس، مع إبقاء مسودات المشاريع بلا رسوم متاحة.
2. فحص النشر يرفض JWT غير صالح، والردود غير المحسومة، وفشل الحساب المخصص؛ فحص قارئ CRM يوجه تبعيته لقاعدة الحسابات.
3. النسخ يستخدم exported snapshot واحدة للتفريغ والأعداد والبنية؛ يسترجع users وidentities فعليًا، ويوقف العمل عند أخطاء الاسترجاع، ويطابق بصمات الدوال والسياسات وRLS والمفاتيح والمشغلات والفهارس.
4. اختبار يوم المكتب يعمل دون تعديل الحاضنة ويعمل في CI بعد فحص القاعدة.
5. CRM يحدث الاسم وحقول الأرض للروابط المعتمدة فقط خلال جلسة مدير متصلة بالحسابات؛ يحمي العملاء ذوي الملاك المختلفين أو المصادر المفقودة، ويحفظ عبر CAS والطابور المعتاد وسجل التدقيق. لا يستهلك مكدس التراجع للعمليات اليدوية.
6. ترحيل 004 يوفر بصمة بيانات المشاريع المرئية عبر RLS. في الهندسة: عند عدم التغيير لا توجد قراءة لصفحات المشاريع؛ عند التغيير تُقرأ مرة واحدة مع فحص قبل/بعد. القاعدة القديمة تستمر بمسار النسختين الآمن. القسم المخفي يتوقف عن المزامنة الدورية ويستأنف عند فتحه.
7. عناصر قائمة CRM أصبحت روابط قابلة للوصول بلوحة المفاتيح مع منع الانتقال الوهمي للـhash.
