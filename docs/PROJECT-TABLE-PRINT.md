# طباعة الصفوف والأعمدة المعروضة في متابعة المشاريع

من «جدول المشاريع» اضغط «طباعة» بجوار تصدير CSV. الفكرة مستمدة من نافذة طباعة سجل CRM، مع إعادة استخدام مصدر الفلاتر وترتيب الأعمدة في المسار الهندسي.

- الاختيار الافتراضي كل نتائج الفلاتر الحالية، حتى لو النتائج موزعة على صفحات. يمكن اختيار الصفحة المعروضة فقط.
- مصدر الصفوف visible()، ومصدر الأعمدة tableGroups()؛ المجموعات المخفية لا تدخل الطباعة. الأعمدة التفصيلية للمراحل المفتوحة تُطبع مع الأعمدة المخصصة وترتيبها الحالي. يمكن استبعاد المزيد من الأعمدة في نافذة الطباعة.
- رقم المشروع والمالك يظلان للطباعة لتعريف كل صف، ويتكرران عند تقسيم الأعمدة إلى أجزاء.
- خيارات A4/A3، أفقي/عمودي، عمود تعليم، توقيع المسؤول. تقسيم الأعمدة مفعّل افتراضيًا لتفادي تصغير جدول واسع جدًا؛ كل جزء يعرض نفس الصفوف مع مجموعة أعمدة مختلفة، ويكرر رأس الجدول عند امتداده لصفحات.
- «معاينة الطباعة» تفتح نافذة مستقلة للقراءة، وبها «طباعة / حفظ PDF». لا تعتمد على محررات الخلايا ولا تنسخ صفحة التطبيق كاملة. إذا حجب المتصفح النافذة، تظهر رسالة واضحة وتبقى إعدادات الطباعة.
- يجب تأكيد الحفظ أولًا قبل فتح/إنتاج المعاينة؛ لا تطبع تعديلات لم يؤكدها الخادم.
- هذه الطباعة تخص جدول المشاريع. جدول الإشراف له تصدير CSV مستقل، وطباعة أقسام المستندات/المهام ليست ضمن هذا الإصدار.

## التحقق
اختبار check-project-print.mjs يستخدم tableGroups الفعلية ويفحص الصفوف المفلترة، الصفحة الحالية، ترتيب الأعمدة، تفاصيل المرحلة، القيم المخصصة الصفرية، استبعاد صفوف غير معروضة، escaping لنصوص HTML، منع الطباعة أثناء الحفظ وحجب النافذة، وتوليد 5000 صف. المعاينة الاصطناعية محفوظة خارج public تحت outputs/project-print-fixtures للاختبار فقط، ولا تحتوي بيانات شركة.

تعذر فتح المتصفح في هذه المحادثة. فحص توليد HTML واجتياز الاختبارات لا يمثلان قبولًا بصريًا أو إثبات طابعة فعلية. لا SQL أو تعديل بيانات المشاريع في هذا الإصدار.
