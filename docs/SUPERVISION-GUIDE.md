# متابعة الإشراف بالموقع

افتح «جدول الإشراف» لعرض المشاريع التي صدرت لها إجازة بناء وما زالت جارية. يعتمد على نفس رقم المشروع والمالك والأرض وملف الحفظ المشترك؛ لا ينشئ مشروعًا موازيًا ولا يغير الحسابات أو استحقاقات الدفعات.

## الاستخدام
1. افتح ملف الإشراف ثم «تعديل بيانات الإشراف» لاختيار الحالة ومهندس الإشراف والملاحظات العامة.
2. أضف زيارة بتاريخها ومرحلتها ومهندسها، واختر مخططة أو منفذة أو ملغاة.
3. الزيارة المنفذة تتطلب نتيجة ولا تقبل تاريخًا مستقبليًا. عند وجود ملاحظات سجل الإجراء ومسؤول المتابعة والموعد.
4. أغلق المتابعة بتسجيل ما تم تنفيذه. لا يمكن اعتبار الإشراف مكتملًا مع وجود متابعات مفتوحة.
5. راجع الحفظ التلقائي بجانب «حفظ الآن». التعديل محفوظ عندما يظهر تأكيد الحفظ؛ أخطاء الاتصال والتعارض لا تُخفى.

## الصلاحيات والحدود
- حفظ بيانات الإشراف والزيارات للمدير وفق صلاحية القاعدة الحالية. أعضاء مساحة المشاريع يطلعون عليها حسب وصولهم؛ إسناد مهندس للإشراف لا يمنحه حق كتابة جديدًا.
- المشروع المتوقف أو المغلق غير قابل لتعديل الإشراف. تسجيل توقف الموقع داخل ملف الإشراف مستقل عن إيقاف المشروع كله.
- تعديل الزيارة يحافظ على معرفها؛ سجل التدقيق الخادمي يحتفظ بالنسخة السابقة. إلغاء الزيارة يتطلب السبب ولا يحذف سجلها.
- مرجع التقرير نص فقط؛ المرفقات وإجراءات اعتماد تقارير الإشراف من الجهة المختصة غير مضمنة هنا. المتابعة الداخلية لا تعني اعتمادًا إنشائيًا أو تصريح صب أو شهادة إنجاز.
- زر CSV داخل جدول الإشراف يصدر الزيارات والملاحظات حسب فلاتر المشاريع الحالية، وليس الصفحة الحالية فقط. الصيغ الخطرة في Excel تعامل كنص.
- عدادات الإشراف محسوبة على النتائج المفلترة. فلتر «متأخرة» يحتسب الزيارات المخططة الماضية والمتابعات المتأخرة.

التحقق الآلي: اختبارات الواجهة بدوال فعلية وDOM اصطناعي، واختبار حفظ فعلي في PostgreSQL معزول وإعادة القراءة ورفض تجاوز صلاحية المهندس. هذا لا يغني عن قبول بصري بعد الدخول على الكمبيوتر والموبايل والطباعة.
