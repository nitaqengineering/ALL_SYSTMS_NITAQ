# نطاق — حزمة الأنظمة الأربعة، 9 نوفمبر 2026

الحسابات، CRM، متابعة المشاريع، واستديو نطاق في بوابة واحدة. هذه حزمة مصدر جاهزة للرفع إلى GitHub؛ الإصلاحات الجديدة لم تُطبّق على قواعد الشركة الحية ضمن هذا الإصدار.

## البدء
1. فك الحزمة وارفع محتوياتها، بما فيها `.github`، إلى مستودع خاص. لا ترفع ZIP نفسه.
2. اقرأ [دليل النشر](DEPLOYMENT-ar.md) قبل تشغيل النشر. تطبيق تحديثات SQL المحددة لكل مشروع يسبق نشر الواجهة.
3. استخدم Node 22.18+ أو إصدارًا مدعومًا يطابق package.json: `npm ci` ثم `npm run check` ثم `npm start`.
4. بعد تعديل `src/accounting.jsx` أو `src/crm.jsx` شغّل `npm run build` ثم الفحص. الملفات الناتجة مضمنة بالحزمة؛ لا يوجد تجميع Babel داخل المتصفح.

## المحتويات
- `public/`: الواجهة الجاهزة للاستضافة، والمكتبات المحلية المثبتة الإصدارات.
- `src/`: مصدر الحسابات وCRM؛ مصدر المسار الهندسي داخل public/engineering.
- `scripts/`: البناء والفحوص والتشغيل المحلي واختبارات SQL المعزولة.
- `database/accounting` و`database/crm` و`database/engineering`: تحديثات هذا الإصدار الأمامية.
- `database/history` و`database/schema-reference`: مراجع تاريخية فقط، لا تُشغّل على القواعد الحالية.
- `supabase/functions`: خدمة دعوة المستخدمين. migrations فارغ عمدًا لتجنب إعادة تشغيل التاريخ القديم.
- [تقرير الإصدار](RELEASE.md)، [نطاق المراجعة وحدودها](AUDIT-20261109-ar.md)، ومراجعة Claude الأخيرة داخل docs/reviews.
